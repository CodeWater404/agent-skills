# Agent Skills

可单独安装的 Agent Skill。每个 Skill 在 `skills/<名称>/` 目录下，入口是其中的 `SKILL.md`。

## emotion-advisor

情感与资源策略问答。先下判断，再分析优势、人性和现实，最后给出具体方案和可以直接说的话术，站在女性的利益一边。

## 安装

**豆包工作区**：把下面这段发到具备 Skill 安装能力的豆包工作区，按提示完成安装。

```text
请从 https://github.com/CodeWater404/agent-skills 安装 emotion-advisor。
只安装 skills/emotion-advisor 目录，并完整保留其中的 references。
```

**其他支持 Skill 的工具**：下载 `skills/emotion-advisor` 整个目录，放进该工具的 Skill 目录即可。
